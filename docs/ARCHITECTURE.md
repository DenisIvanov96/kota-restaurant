# Architecture

- **Type:** static website, no backend (Backend Developer inactive).
- **Files:** `index.html` (single page), `css/style.css`, `js/main.js`, `images/`.
- **External resources:** Google Fonts stylesheet only.
- **APIs:** none. If a booking/contact form needs to store or send data, the Backend Developer first evaluates a hosted form service vs. a small server and records the choice in `docs/DECISIONS.md`.
