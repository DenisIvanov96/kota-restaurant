# Kota Restaurant

Website for Kota Restaurant.

## Structure

- `index.html` — main page (hero, menu, about, contact)
- `css/style.css` — styles
- `js/main.js` — scripts
- `images/` — photos and assets

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```
